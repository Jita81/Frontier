# Redaction note

Game text and game graphics belong to Frontier Developments. This branch keeps
none of them:

- Screenshots and other images of game screens are not tracked. They live only
  in the local working copy (`docs/experiments-local/`, excluded from git).
- Where a log, transcript or write-up quoted a sentence from the game, the
  quote is replaced by a placeholder of the form `[fe2.s:NNNNN]`, which names
  the line of the original source where the text lives. Short labels and names
  (stations, systems, commodities, menu titles) stay as they are.

The branch history was rewritten on 2026-10-25 to remove the originals. Any
new evidence must follow the same rule before it is committed.
